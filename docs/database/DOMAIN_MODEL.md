# ACL Domain Model

## Status

Draft

## Purpose

This document defines the core domain entities and relationships for ACL.

The database schema must be derived from this domain model rather than
created independently.

---

# Core Domains

## Identity

Responsible for:

- Users
- Profiles
- Authentication identities
- Sessions
- Account status

## Access Control

Responsible for:

- Roles
- Permissions
- Role assignments
- Permission evaluation
- Scoped authorization

## Institutions

Responsible for:

- Universities
- Colleges
- Faculties
- Schools
- Departments
- Institutional configuration

## Academics

Responsible for:

- Programmes
- Academic sessions
- Semesters
- Levels
- Courses
- Course offerings
- Enrollments

## Learning

Responsible for:

- Learning paths
- Modules
- Chapters
- Lessons
- Learning resources
- Practical activities

## Assessments

Responsible for:

- Assessments
- Questions
- Question banks
- Attempts
- Answers
- Submissions
- Grades

## Content

Responsible for:

- Educational content
- Documents
- Media references
- Content versions
- Content approval

## Community

Responsible for:

- Discussions
- Posts
- Comments
- Reactions
- Groups

## Messaging

Responsible for:

- Conversations
- Messages
- Participants

## Notifications

Responsible for:

- In-app notifications
- Email notifications
- Notification preferences

## Payments

Responsible for:

- Orders
- Transactions
- Payment providers
- Refunds
- Payment status

## Marketplace

Responsible for:

- Tutors
- Tutorials
- Products/services
- Purchases

## AI

Responsible for:

- AI providers
- AI requests
- AI usage
- AI-assisted features
- AI generated content
- Human approval workflows

## Analytics

Responsible for:

- Learning analytics
- Engagement metrics
- Academic analytics
- Platform metrics

## Audit

Responsible for:

- Security events
- Administrative actions
- Important data changes
- Compliance records
